# Sentence plans: select one section

Read the relevant rule file in full. Fill the plan with actual content, then produce clean prose; the plan stays in review notes unless requested. For a local edit, plan only the affected unit and check continuity. Counts are the selected journal-method house profile, not official IEEE limits.

| Section | Detailed blueprint | Required functional outline |
| --- | --- | --- |
| Abstract | [section-abstract.md](../rules/section-abstract.md) | A1 value; A2 route; A3 mismatch/consequence; A4 method/principle; A5 framework; A6 mechanism A; A7 complementary requirement B; A8 necessary adaptation/output; A9 scoped evidence |
| Introduction | [section-introduction.md](../rules/section-introduction.md) | P1 task; P2 route/barrier; P3 existing approaches; P4 tension/questions; P5 design responses; P6 contributions; P7 nearest-neighbor distinction; P8 roadmap; each with sentence tasks |
| Related Work | [section-related-work.md](../rules/section-related-work.md) | R1 research line; R2 2–3 sentences: condition → consequence → positioning, target 35–65 words, max 80 and no longer than R1 |
| Method | [section-methodology.md](../rules/section-methodology.md) | M1 local summary; M2 input; M3 purpose; M4 equation; M5 symbols/axes; M6 interpretation; M7 consumer |
| Experiments | [section-experiments.md](../rules/section-experiments.md) | All paragraphs topic-first; E1 factor/finding; E2 verified comparison; E3 evidence; E4 operation A; E5 functional contrast/relevance; E6 bounded implication; failures F1–F7 |
| Conclusion | [section-conclusion.md](../rules/section-conclusion.md) | C1 thesis; C2–C4 complementary mechanism roles; C5 supported evidence; C6 boundary |

```text
Requested unit / single argumentative task:
Slot ID | Actual content to write | Source | Transition/relation | State
...
Opening total statement:
Operational explanation (operation → function → observation relevance):
Closing implication / scope:
Adjacent merge or functional remapping: reason + actual carrier sentence
```

Do not leave empty form fields for the author to fill when the materials already supply the answer. Missing facts remain a local evidence item, not invented completed prose. Function remapping preserves real motivation and mechanisms; it is not a general exemption from structure.

Every section blueprint ends with a hardened checklist (`S-ABS-H`, `S-INT-H`, `S-RW-H`, `S-MET-H`, `S-EXP-H`, `S-CON-H`) distilled from rejected drafts. Fill the plan from the blueprint, then check the result against that checklist before delivery. The shared rules it depends on are indexed in [core/WORKFLOW.md](../WORKFLOW.md) §9.
