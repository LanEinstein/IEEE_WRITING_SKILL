# Submission checklist

Last gate before the PDFs leave the machine.

## Official requirements, checked at source

- [ ] The current official instructions were read today, for this year, track and article type.
- [ ] Page limit, and what counts toward it (references, statements, appendices), matches what was built.
- [ ] Template, class file and options are the official ones; margins, font sizes and column widths are unmodified.
- [ ] Anonymity, required statements, checklists, supplementary rules, file formats and naming meet the current instructions.
- [ ] The declared subject area and keywords match the paper.

## Manuscript integrity

- [ ] The shipped PDF contains the latest approved text: a sentence changed in the last round is present.
- [ ] No draft markers, internal codes, hashes, review-round notes, comments or AI-trace text in sources or PDF.
- [ ] No personal data, machine paths or private identifiers in the PDF metadata or embedded figures.
- [ ] Every reference verified at a primary record: authors, title, venue, volume, pages, year, DOI or identifier.
- [ ] Every citation is cited in the text and every reference is cited at least once.
- [ ] Numbers, tables, figures and captions agree with the admitted evidence.
- [ ] Terminology, abbreviations and symbols consistent across main text and supplement.

## Layout

- [ ] Every page rendered and inspected: reading order, float placement, caption legibility, column balance.
- [ ] No orphan or widow line, no heading alone at a page bottom, no sparse page in the supplement.
- [ ] Build log clean: no unresolved references, no missing citations, no "rerun" warnings.
- [ ] The main text ends where the venue's page rule allows, verified by reading the last page.

## Evidence and claims

- [ ] Abstract, Introduction, Conclusion and the results sections agree on scope, quantifiers and ranks.
- [ ] No claim of deployment, clinical use, security capability or priority without evidence.
- [ ] Limitations placed where they affect interpretation, once, without a defensive inventory.

## Delivery

- [ ] Only the designated PDFs are in the submission folder; nothing else.
- [ ] File names, versions and dates in the submission record.
- [ ] Open questions for the authors listed explicitly, with the affected sentence.
