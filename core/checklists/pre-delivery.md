# Pre-delivery checklist

Run before showing any unit to the author. Report which items ran and which did not.

## The unit itself

- [ ] The requested scope is complete: every paragraph of the authorized unit, not the first one.
- [ ] Each paragraph has one argument, and its first sentence states it.
- [ ] Each observation is followed by its analysis, joined by the observation's subject.
- [ ] Each paragraph ends on its own theme; no new fact after the logical endpoint.
- [ ] No paragraph repeats a fact already stated in a neighbouring paragraph or in the Abstract.
- [ ] No sentence is its own paragraph.
- [ ] Nothing in the text is internal (draft codes, stages, file names, development order, review rounds).

## Evidence

- [ ] Every claim traces to an admitted source or record; every number matches its table.
- [ ] Every derived value was computed with a tool and re-read.
- [ ] Comparison, metric, protocol, direction and scope are in the sentence or its neighbour.
- [ ] Unfavourable results are present where the argument needs them, read honestly, ending on what this work establishes.
- [ ] No claim is stronger than the evidence, and none is weaker than the evidence supports.

## Language

- [ ] No sentence was translated from a plan, an instruction or a Chinese draft; each was written from its function.
- [ ] No Chinese-origin structure survives (TD2 classes T1–T8).
- [ ] Each connective states a relation that holds by itself.
- [ ] One connective or limiter per paragraph; no phrase repeated within a sentence.
- [ ] Repetition was counted, not guessed; replacements did not create a new dominant word.
- [ ] No bare demonstrative; every pronoun has one possible referent.
- [ ] No colon or dash in body prose; no semicolons in captions.
- [ ] Absolutes (must, any, every, only) checked against the tested scope.

## Terms, symbols, display items

- [ ] Every term, abbreviation and symbol is defined before this unit's first use in the reader's path.
- [ ] One name per object; no renaming for variety; no invented concept without a definition.
- [ ] Every symbol appears at least twice and has one meaning; displays are explained and used.
- [ ] Figure and table names match the text; each float is cited where the reader needs it.
- [ ] Captions state only what is needed to read the float; multi-panel floats name each panel in one short sentence.

## Process

- [ ] A self-review pass ran and its fixes are reported.
- [ ] `scripts/prose_lint.py`: H = 0; each S fixed or justified in one line.
- [ ] `scripts/pronoun_check.py`: H = 0; each S replaced or justified.
- [ ] The applied text was re-read in context after writing.
- [ ] Layout was measured, not estimated, if the change can move text.
- [ ] Open items are listed: what is pending, what needs the author's decision, what was not checked.
