# Use exemplars for argument structure

Published papers and private local exemplars can show how to organize a task, but neither supplies missing research facts nor overrides current official requirements. This file supersedes the earlier quote bank and corpus-derived mandatory claims. Historical corpus notes under `local/` are observations, not current execution rules.

Select a small number of relevant full papers by task, method type, and venue. For each, record the **sentence function → evidence type → logical transition**, then write original prose from the current paper's facts. Do not copy unpublished manuscript wording, data, or identifiers into a reusable artifact or another paper. Do not quote an abstract bank to complete method slots.

| Observe | Apply using the maintained reference |
| --- | --- |
| How a reasonable route meets a specific assumption mismatch | [Introduction sentence blueprint](../rules/section-introduction.md) |
| How the abstract moves from motivation to principle and evidence | [A1–A9](../rules/section-abstract.md) |
| How the subsection closes with a short technical position | [Related Work](../rules/section-related-work.md) |
| How equations connect inputs to output consumers | [Method](../rules/section-methodology.md) |
| How result paragraphs explain operations rather than repeat cells | [Experiments](../rules/section-experiments.md) |

Do not import an exemplar's fixed two-limitations story, statistical claims, missing comparison, suppressed boundary, compulsory diagnostic figure, or venue-specific layout. Existing novel phenomena can be named if operationally defined and supported; no new diagnostic experiment is required by a writing template. Conference formatting follows its current year/track instructions; do not assume a journal caption length or an IEEEtran class.
