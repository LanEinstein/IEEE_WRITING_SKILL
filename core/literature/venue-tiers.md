# Literature quality and optional author preferences

Relevance, accurate attribution, and content support govern citations. This file no longer supplies an automatic venue allow/deny list. Original datasets, software, standards, workshops, reports, and preprints can be necessary sources; never replace an original source with an unrelated prestigious paper.

An author may explicitly request a literature-selection preference. Record its scope, rationale, and exceptions in the project configuration; apply it without falsifying attribution or hiding relevant prior work. Do not add case-by-case approval friction merely because a source is outside a historical tier list. If a preference conflicts with necessary accurate credit, identify the specific issue and offer an accurate alternative.

Published versions should be checked when citing a preprint. A title/year index match is not evidence that a paper supports a claim. See [citations-policy.md](../rules/citations-policy.md).
