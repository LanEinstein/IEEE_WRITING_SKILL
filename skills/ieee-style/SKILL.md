# ieee-style: scoped style and format audit

Resolve `<suite>` by following this entry directory's symlink to its real path; the suite root contains `core/` two levels above. Read [core/WORKFLOW.md](../../core/WORKFLOW.md) once, then only the resources needed below. Read the relevant section rule file in full before drafting/reviewing that section; do not replace its sentence tables with a remembered summary. Current session authorization and project agreements govern editing; presentation size never creates permission. Scientific accuracy and current official requirements constrain every house preference.

The shared rule set under `core/rules/` is binding for the requested unit: [paragraph-architecture.md](../../core/rules/paragraph-architecture.md), [sentence-craft.md](../../core/rules/sentence-craft.md), [lexicon.md](../../core/rules/lexicon.md), [translation-discipline.md](../../core/rules/translation-discipline.md), [voice-and-positioning.md](../../core/rules/voice-and-positioning.md), [terminology-and-notation.md](../../core/rules/terminology-and-notation.md), [figure-standards.md](../../core/rules/figure-standards.md) and, where the text is revised, [revising.md](../../core/rules/revising.md) and [review-loops.md](../../core/rules/review-loops.md). [QUICK_REFERENCE.md](../../QUICK_REFERENCE.md) is the one-page digest. Each section blueprint ends with a hardened checklist `S-*-H`. For English prose, run `scripts/prose_lint.py` (H must be zero) and then `scripts/pronoun_check.py`; both are diagnostics, not proof.

1. Infer the requested scope and venue from available context. Unknown venue stays provisional: assess writing quality, not an invented TIP/TPAMI cap. For mechanical compliance, read [venue-style-profiles.md](../../core/literature/venue-style-profiles.md) and [ieee-facts.md](../../core/templates/ieee-facts.md), then verify the specific current official requirement.
2. Read [prose-rules.md](../../core/rules/prose-rules.md) and only the relevant [section rules](../../core/templates/sentence-plan.md). For figure/table tasks also read [figure-standards.md](../../core/rules/figure-standards.md). Abstract-only review skips other sections, the whole float inventory, and full-paper compilation.
3. Check sentence/paragraph functions and actual logic, not keywords alone. Retain the house profile's concrete blueprints while distinguishing an author preference from a verified venue requirement. Scientific inconsistencies affecting meaning should be identified with evidence, not silently repaired.
4. Use [verification-protocol.md](../../core/rules/verification-protocol.md) for available checks. For a read-only review, compile only an isolated copy if needed; preserve the original source, bibliography, figures, PDFs, and auxiliary outputs. PDF/plain text is acceptable with source/build checks marked unavailable. No scientific-review panel is required for a style task.
5. Deliver a compact report: scope/version/profile; applicable checks with PASS / ISSUE / NOT_CHECKED / NOT_APPLICABLE; prioritized findings. Each finding gives location or quote, expectation and its rule class, impact, and a concrete fix. Do not call a house preference an IEEE violation. Measured sweep hits need contextual interpretation; a nonzero pronoun count is not automatically a defect.

Do not edit the manuscript. The requested report may be written in the agreed output area. Finish with the few fixes that materially improve the requested unit and the remaining verification limits. Do not fabricate findings or acceptance probabilities.
