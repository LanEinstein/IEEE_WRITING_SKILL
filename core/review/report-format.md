# Review report: concise evidence, usable next actions

Use one requested report in the agreed output area, or respond directly for a small task. Manuscript/bibliography/figures/original build outputs remain unchanged. Scale the report to the requested scope; no compulsory five-panel theater for a paragraph review.

1. **Scope/version:** actual sources, reviewed units, mode/profile, target requirements verified or pending, independent-vs-serial review status.
2. **Scientific findings:** prioritized and deduplicated, with severity, quote/location, evidence, impact, minimum fix, and confidence. Distinguish actual contradiction, missing evidence, and a plausible interpretation.
3. **Writing/venue audit:** house sentence/paragraph checks and official requirements separately classified. Tool results are observed diagnostics; cite the artifact and scope. Unavailable checks are NOT_RUN, not PASS.
4. **Actions:** the few changes needed, decisions affecting claim scope, and pending facts. If requested, give a bounded internal decision estimate, never a calibrated probability or a real editorial verdict.

Full review can append per-lens notes and a conflict-resolution matrix where useful. Internal author bookkeeping need not be copied into the manuscript/response letter, but material scientific concerns must not be hidden by calling them internal strategy.

Re-review adds a row per prior finding: `ADDRESSED / PARTIAL / OPEN / REGRESSED`, evidence in revised text, remaining action. Check claimed fixes against the actual artifact; do not trust a response letter alone. New findings use the same evidence standard. If the prior report is unavailable, mark traceability pending and deliver the current-version review.
