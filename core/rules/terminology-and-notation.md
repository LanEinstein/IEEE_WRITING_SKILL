# Terminology and notation

Consistency failures read as sloppiness to a reviewer and are cheap to avoid.

## TN1. One object, one name

Every technical object, metric, protocol and component has exactly one canonical name. Do not rename it for variety, do not abbreviate it inconsistently, and do not use two names for the same quantity in different sections. When two names exist for one quantity (for example a weighted and an unweighted variant that turn out to be identical), keep one, delete the other and delete its definition.

Canonical names come from the field first, the method's own definition second. A term the paper defines is capitalised or emphasised once, then used plainly.

## TN2. Define before use, everywhere

The first use in the main text carries the definition or an immediate gloss. This applies to abbreviations, paper-defined concepts ("diagnostic controls"), protocol names, group names ("confirmation group") and symbols. Check with a search before delivery: every reuse must have a definition earlier in the reader's path.

The supplement may define more, but a term the main text relies on is defined in the main text.

## TN3. Abbreviations

Expand at first use with the abbreviation in parentheses, then use the abbreviation. Never open a paragraph with a bare abbreviation or bare letters; write the full name once inside the paragraph if the reader may have lost it. Do not abbreviate a term used only twice.

## TN4. Symbols: the minimum necessary set

- Introduce a symbol only where it is used more than once, or where a formula needs it. A symbol appearing once is replaced by words.
- A symbol used in the main text is defined in the main text. If the definition moved to the supplement, use the name instead of the symbol.
- One symbol, one meaning. Check that a letter used for a transform is not also used for a matrix, a count or a module.
- Use conventional, readable notation. Skip set-cardinality and other unusual marks ("#") that most readers have to look up; write the count out or use a standard symbol with a definition.
- Keep a symbol's typography: scalars, vectors, matrices, sets and operators follow one convention, and text subscripts are upright.

## TN5. Formulas

- A formula earns its place: a key operation defined in words and then in one line of mathematics, not a trivial identity occupying a display.
- Every symbol in the display is defined in the sentence before or the line after, and appears again only with its defined meaning.
- The display is part of the sentence: punctuation and the "where" clause are attached properly.
- Explain what the operation means and what it preserves, not only what it is.
- Do not use a display to save words that a clause would state more clearly; conversely, a definition the reader must reuse deserves a display.
- Keep display spacing local; do not pad a page with vertical space around short formulas.

## TN6. Figure and text must agree

Panel labels, axis labels, legends, node names, symbols and section numbering match the text exactly, including hyphenation and capitalisation. If the figure uses a symbol the text defines later, the caption gives one phrase so the figure can be read where it appears.

## TN7. Section, figure and table references

Use one form throughout ("Sec.", "Secs.", "Fig.", "Figs.", "Table"), including at the start of a sentence. Cross-references to the supplement are marked as such and stay consistent with the split of the two documents.

## TN8. Bold and emphasis

Bold marks a paper-defined term or a system name at its formal introduction, following the target venue's habit; it is not used for emphasis of ordinary claims. Italic marks a defined term; quotation marks are not used for scare quotes.

## TN9. Consistency sweep before delivery

Search the whole manuscript for each canonical name, abbreviation and symbol. Report every variant spelling, every abbreviation expanded twice, every symbol with two meanings, and every name used before its definition.

## TN10. Do not invent a concept

A self-coined term ("signal energy", "stage dynamics") costs the reader a definition. Either define it once, precisely, in the sentence that needs it, or use the field's word. A term the author has not defined and the field does not use is not allowed.
